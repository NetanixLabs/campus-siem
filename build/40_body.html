Email Delivery — Alert Actions
resend · server-side
Alert mail is sent through Resend by this deployment's own /api/send route, which reads RESEND_API_KEY from the server environment. Nothing to configure here — no key is ever stored in or sent from the browser.
Until a domain is verified at resend.com/domains, Resend only delivers to the address the account was created with — so Recipient must be that address. Verify a domain and set ALERT_FROM to reach anyone else.
